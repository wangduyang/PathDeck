TaskGlass.StartHost.exe
  Locally authored minimal x86 host; source and build script included in Sources.
  Source of truth: D:\codex\TaskGlass\native\StartHost.
  Imports only Windows system DLLs (KERNEL32.dll, SHELL32.dll, msvcrt.dll).
  It loads only the local official x86 engine, checks the three session exports,
  validates local portable storage and an exact two-process allowlist, watches its
  TaskGlass parent and named stop event, ends the engine session, and exits.
  --probe loads and checks exports only; it never starts an injection session.
